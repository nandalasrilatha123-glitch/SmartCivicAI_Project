# SmartCivicAI Project

SmartCivicAI is an AI-powered civic complaint management platform that helps citizens report issues, enables officers to manage complaints efficiently, and provides administrators with analytics and monitoring tools.

## Features

- Citizen complaint registration
- AI-assisted complaint categorization
- Complaint tracking and status updates
- Officer dashboard for issue management
- Admin dashboard with analytics
- Multilingual support
- Notification system
- GIS map integration
- Secure authentication and authorization

## Technology Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- MongoDB

### AI/ML
- YOLO Model
- Complaint Classification
